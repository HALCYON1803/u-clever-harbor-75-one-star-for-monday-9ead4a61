A one-star restaurant review of Monday, written as if Monday were a
restaurant — the worst table in the house, the weekend served cold,
and a bill for the whole week. One line, twenty words, plain text.

## The entry

> One star. Monday seated us by the alarm clock, served the weekend cold, and billed us for the whole week.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` and asserts the gate
itself: 1–180 characters, at most 25 words, a single line, and no
trailing newline. The file is then read back and checked byte for
byte against the review.
